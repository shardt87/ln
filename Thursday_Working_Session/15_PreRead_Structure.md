# 15. Pre-Read Structure (approved before build)

The blueprint for the rebuilt visual pre-read. Nothing gets designed until this structure stands. The narrative follows the pyramid principle: the answer first, three supporting arguments, then execution and the ask. One message per frame, one exhibit per frame, no frame carrying more than one idea.

## Why the last version failed, and what this one changes

The scrapped version crammed the entire working pack onto dense letter pages: five-figure tables, nine-cell grids, three frameworks per page, half-empty closings. This structure inverts that: ten frames, each carrying a single message title, a single visual, and at most forty words of support. Detail lives in the markdown pack (files 00-07); the pre-read sells the argument, the pack proves it.

## Narrative arc

ANSWER: launch a 90-day federated pilot with two validation priorities.
ARGUMENT 1 (evidence): activity is real, but nothing is proven past targeting.
ARGUMENT 2 (portfolio): the evidence supports exactly two priorities now.
ARGUMENT 3 (model): federated orchestration wins because nothing has to move.
EXECUTION: dated gates, pre-agreed exit criteria, honest KPIs.
ASK: three decisions from Marc Thursday; one decision from Amber in September.

## Design system

- Canvas: 1920 x 1080 frames (screen-first pre-read; exports cleanly to PDF and PowerPoint sizes).
- Palette from the brand artwork: near-black #131315 ground, copper #C08552 and #B87A50 accents, warm white #F3EFE9 text, one muted green #5E8A6A reserved for "go" states. Dark throughout; no light pages, so the document reads as one piece with the cover.
- Typography: one display serif for message titles, one grotesque sans for everything else; large sizes, extreme restraint. Message titles are full sentences, 44-60px. Support text never below 20px.
- Motif: the hexagon from the artwork, used once per frame as a quiet structural element, never as decoration spread.
- Sources: one short line per frame, bottom left, citing S-refs. Confidential mark bottom right.
- Rule of thumb enforced per frame: if a frame needs a second exhibit, the frame is wrong.

## Build path and toolchain

1. This structure commits to GitHub first (this file).
2. The design is authored as self-contained HTML frames per the Adobe visual-design playbook, with font selection through the Adobe font tools.
3. The HTML passes the Adobe export-readiness validation, then exports to Adobe Express as a native document Stephan can edit, share, and export to PDF or PPTX from the Express editor.
4. The design source HTML commits to the repo alongside this structure so the document is reproducible.
