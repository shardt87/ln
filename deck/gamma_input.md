# APPENDIX 4 — Benchmark arithmetic

**Prefab spine case — adjacent-market benchmark.**

A fuel cell manufacturer's prefab program: 4,400 → ~880 field hours per installation.

Dollar math: $418K field labor at stick-build → $83.6K prefab → $334K saved per unit. Extrapolated across a 100-unit program: $33.4M.

**Caveat band:** Adjacent-market benchmark from a fuel cell manufacturer's program — not an NRG or Southwire-project result. Gross is not net. Installed cost is higher — the argument is TCO over asset life. This slide exists so the main deck never carries dollar math.
